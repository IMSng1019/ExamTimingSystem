# 考试倒计时显示系统设计

## 目标

构建一个本地运行的考试倒计时桌面系统，使用 Electron + React + Nest.js + TypeScript。系统主界面复原参考图中的蓝底白字考试倒计时页面，支持考试状态显示、响铃规则、科目选择、文字自定义、配置导入导出和本地音频文件夹选择。

## 技术架构

- Electron 负责桌面窗口、原生文件/文件夹选择、全屏显示和本地启动编排。
- React 负责倒计时主界面、设置界面、科目多选和配置编辑。
- Nest.js 负责配置文件读写、配置校验、音频目录扫描和本地 API。
- TypeScript 覆盖前端、后端和 Electron 主进程。

应用本地运行，不依赖局域网或远程服务。Electron 启动后拉起 Nest 后端，并加载 React 前端。

## 主界面复原

主界面为全屏蓝色背景、白色文字，布局参考图片：

- 顶部居中标题：例如“西大附中高三二诊定时检测指令”。
- 标题下方显示考试科目、开考时间、结束时间。
- 科目行显示“考试科目：生物 准备”一类内容，其中状态随时间变化。
- 中部显示超大当前时间，格式为 `HH:mm:ss`。
- 底部显示倒计时说明，例如“离开始还有：1小时5分钟”。
- 最底部显示两段单位文字。

字体优先使用 Windows 常见中文宋体风格字体：`SimSun`, `宋体`, `serif`。主时钟使用 serif 数字字体，贴近参考图中的大号白色数字。

## 状态规则

系统每秒根据当前时间、当前科目开始时间和结束时间计算状态：

- 当前时间早于开始时间：显示“准备”。
- 当前时间在开始时间和结束时间之间：显示“进行中...”。
- 当前时间晚于结束时间：显示“结束”。

倒计时说明根据状态变化：

- 考试前：显示距离开始还有多久。
- 考试中：显示距离结束还有多久。
- 考试后：显示已结束。

状态文字和提示文字均可在设置中修改。

## 科目设置

支持科目：

- 语文
- 数学
- 英语
- 物理
- 化学
- 生物
- 政治
- 历史
- 地理

每个科目可单独设置开始时间和结束时间。倒计时页中点击科目文本时，打开科目多选面板。多选结果用顿号连接，例如“语文、数学、英语”。

## 设置界面

按下 `Esc` 打开或关闭设置界面。设置界面包含：

- 页面文字设置：标题、字段名、状态文字、倒计时提示、底部单位文字。
- 科目时间设置：每科开始时间、结束时间。
- 当前显示科目设置：支持多选。
- 音频目录设置：通过 Electron 原生对话框选择文件夹。
- 响铃规则设置：添加、删除、启用、禁用规则。
- 配置文件操作：保存当前设置为 JSON 文件，读取 JSON 文件恢复设置。

## 响铃规则

内置默认响铃点：

- 考试开始。
- 考试结束。
- 考试开始前 15 分钟。
- 考试开始前 5 分钟。

用户可添加自定义规则：

- 相对事件：考试开始前、考试开始后、考试结束前、考试结束后。
- 时间偏移：分钟或秒。
- 音频文件：从已选择音频文件夹中选择。

为避免重复播放，同一规则在同一次考试时间窗口内只触发一次。切换科目、修改时间或重新导入配置后，会重新计算触发状态。

## 文件与数据

配置以 JSON 保存，主要结构包含：

- 显示文字。
- 科目列表和每科时间。
- 当前选中科目。
- 音频目录。
- 响铃规则。

Nest 后端提供本地 API：

- 读取当前配置。
- 保存当前配置。
- 导入配置校验。
- 扫描音频目录并返回可播放文件。

Electron 通过原生文件对话框实现：

- 选择音频文件夹。
- 保存配置文件。
- 读取配置文件。

## 错误处理

- 配置文件格式错误时显示明确提示，并保留当前配置。
- 音频目录不存在或不可读时显示提示，响铃规则不播放。
- 指定音频文件缺失时跳过该规则并提示。
- 时间设置无效时禁止保存对应科目配置。

## 验证

实现完成后至少验证：

- React 前端构建通过。
- Nest 后端构建通过。
- Electron 能启动窗口。
- `Esc` 可打开设置。
- 状态在考试前、考试中、考试后正确变化。
- 默认响铃规则和自定义响铃规则只触发一次。
- 配置可导出并重新导入。
- 音频文件夹可选择并列出音频。
